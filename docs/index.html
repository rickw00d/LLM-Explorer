LLM Explorer

Side-by-side AI generation across models — video & images, fully local多模型 AI 生成比較工具 — 影片 & 圖片，本機全離線
🎞️ LTX-2.5 · H3 · Wan 🖼️ FLUX.2 · Qwen · HiDream 🖥️ NVIDIA GB10 · 128GB

Features 功能特色

⚡ Same prompt, side by side

Same prompt and same seed, sent to several models in one click; results line up next to each other so quality differences are obvious.相同提示詞 + 相同 Seed，一鍵送出多個模型同時生成，結果並排顯示，直觀比較品質差異。

🎲 Prompt generator

A built-in random prompt engine: 12 subject descriptions, 30 actions, 18 scenes with matching audio, and a range of camera styles.內建豐富的隨機提示詞引擎：12 種角色描述、30 種動作、18 種場景與匹配音效、多種攝影風格。

🔒 Fully offline

Every model runs locally and nothing leaves the machine. Bound to localhost, so generation needs no internet connection.所有模型在本機執行，資料不外流。綁定 localhost，無需網路連線即可生成。

📐 Multiple resolutions

Video: SD / HD / FHD / 2K. Images: 1:1 / 4:3 / 3:4 / 16:9 / 9:16, tuned to each model's native resolution.影片：SD / HD / FHD / 2K。圖片：1:1 / 4:3 / 3:4 / 16:9 / 9:16。依模型原生解析度最佳化。

🚀 Tuned for GB10

NVFP4 quantisation, Sol-Attn sparse attention, FirstBlockCache and TeaCache — H3 went from 1200s down to 298s.NVFP4 量化、Sol-Attn 稀疏注意力、FirstBlockCache、TeaCache — H3 從 1200s 加速至 298s。

💾 Live monitoring

Each finished run reports elapsed time and VRAM usage, so resource cost stays visible. Click an image to open the full-size version.每次生成完成顯示耗時與 VRAM 使用量，輕鬆掌握資源消耗。圖片可點擊開啟原圖檢視。

Optimisations 優化技術

🔢 NVFP4 quantisation

Blackwell's native 4-bit mixed-precision format. FLUX.2 drops from 34 GB to 22 GB, memory traffic falls by 35%, and throughput rises roughly 30-40%.Blackwell 原生 4-bit 混合精度格式。FLUX.2 從 34GB 降至 22GB，記憶體搬運減少 35%，速度提升約 30-40%。

⚡ Sol-Attn sparse attention

H3-specific speed-up. tau=1.3 is stable at HD; at higher resolutions watch the token count.H3 專用加速。tau=1.3 在 HD 解析度下穩定運作，高解析度需注意 token 數限制。

🧊 FirstBlockCache

Caches the first transformer block's output to avoid recomputation. Threshold 0.1, at most 2 consecutive hits.快取第一層 transformer block 的計算結果，減少重複運算。閾值 0.1，最大連續命中 2 次。

🍵 TeaCache

H3-specific temporal cache: when the difference between adjacent steps falls below the threshold, the step is skipped, speeding up the denoising loop.H3 專用時序快取。相鄰步之間差異小於閾值時跳過計算，加速 denoising loop。
