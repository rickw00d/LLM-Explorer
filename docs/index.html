LLM Explorer

Multi-model AI generation compared side by side — video & images, fully local
🎞️ LTX-2.5 · H3 · Wan 🖼️ FLUX.2 · Qwen · HiDream 🖥️ NVIDIA GB10 · 128GB

Features

⚡ Same prompt, side by side

Same prompt and same seed, sent to several models in one click; results line up next to each other so quality differences are obvious.

🎲 Prompt generator

A built-in random prompt engine: 12 subject descriptions, 30 actions, 18 scenes with matching audio, and a range of camera styles.

🔒 Fully offline

Every model runs locally and nothing leaves the machine. Bound to localhost, so generation needs no internet connection.

📐 Multiple resolutions

Video: SD / HD / FHD / 2K. Images: 1:1 / 4:3 / 3:4 / 16:9 / 9:16, tuned to each model's native resolution.

🚀 Tuned for GB10

NVFP4 quantisation, Sol-Attn sparse attention, FirstBlockCache and TeaCache — H3 went from 1200s down to 298s.

💾 Live monitoring

Each finished run reports elapsed time and VRAM usage, so resource cost stays visible. Click an image to open the full-size version.

Optimisations

🔢 NVFP4 quantisation

Blackwell's native 4-bit mixed-precision format. FLUX.2 drops from 34 GB to 22 GB, memory traffic falls by 35%, and throughput rises roughly 30-40%.

⚡ Sol-Attn sparse attention

H3-specific speed-up. tau=1.3 is stable at HD; at higher resolutions watch the token count.

🧊 FirstBlockCache

Caches the first transformer block's output to avoid recomputation. Threshold 0.1, at most 2 consecutive hits.

🍵 TeaCache

H3-specific temporal cache: when the difference between adjacent steps falls below the threshold, the step is skipped, speeding up the denoising loop.
