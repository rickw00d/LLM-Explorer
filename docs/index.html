LLM Explorer

多模型 AI 生成比較工具 — 影片 & 圖片，本機全離線
🎞️ LTX-2.5 · H3 · Wan 🖼️ FLUX.2 · Qwen · HiDream 🖥️ NVIDIA GB10 · 128GB

功能特色

⚡ 同 Prompt 並排比較

相同提示詞 + 相同 Seed，一鍵送出多個模型同時生成，結果並排顯示，直觀比較品質差異。

🎲 智能提示詞生成

內建豐富的隨機提示詞引擎：12 種角色描述、30 種動作、18 種場景與匹配音效、多種攝影風格。

🔒 完全離線

所有模型在本機執行，資料不外流。綁定 localhost，無需網路連線即可生成。

📐 多解析度支援

影片：SD / HD / FHD / 2K。圖片：1:1 / 4:3 / 3:4 / 16:9 / 9:16。依模型原生解析度最佳化。

🚀 GB10 深度優化

NVFP4 量化、Sol-Attn 稀疏注意力、FirstBlockCache、TeaCache — H3 從 1200s 加速至 298s。

💾 即時監控

每次生成完成顯示耗時與 VRAM 使用量，輕鬆掌握資源消耗。圖片可點擊開啟原圖檢視。

優化技術

🔢 NVFP4 量化

Blackwell 原生 4-bit 混合精度格式。FLUX.2 從 34GB 降至 22GB，記憶體搬運減少 35%，速度提升約 30-40%。

⚡ Sol-Attn 稀疏注意力

H3 專用加速。tau=1.3 在 HD 解析度下穩定運作，高解析度需注意 token 數限制。

🧊 FirstBlockCache

快取第一層 transformer block 的計算結果，減少重複運算。閾值 0.1，最大連續命中 2 次。

🍵 TeaCache

H3 專用時序快取。相鄰步之間差異小於閾值時跳過計算，加速 denoising loop。
